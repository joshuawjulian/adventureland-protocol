Each level costs about 22% more than the level before. The cost doubles about every 3.5 levels.

A level-80 character gets the same xp from a goo as a level-1 character.

Level 80 is a goal for a long time.

Source: G.levels (G 17478); node/server.js:1305-1316

G.levels[N] is the xp to go from level N to N+1. The server keeps the xp toward the next level, not a total. A monster gives its base xp times your xp multiplier; in a party each member gets a share. At level 70 the server tells everyone on the server about each new level, at 80 it tells all servers.
